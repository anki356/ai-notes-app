# AI Notes App

An intelligent, privacy-first note-taking application featuring Markdown editing, AI summaries, semantic search, and voice notes.

## Features
- **Markdown Editor:** Rich editing experience with live preview.
- **AI Summaries:** Automatically condense long notes into key points.
- **Semantic Search:** Find notes based on meaning and context, not just keywords.
- **Voice Notes:** Record and transcribe audio notes directly into your workspace.
- **Local Embeddings:** Privacy-focused vector search running on your device.
